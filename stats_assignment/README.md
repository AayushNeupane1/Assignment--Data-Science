# Statistics Assignment

This folder contains a Jupyter notebook demonstrating statistical analysis and data visualization using Python.

## Files

### Statistics_module.ipynb
A comprehensive notebook covering statistical operations and visualizations.

## Content Overview

### Libraries Used
- `statistics` - Built-in Python statistics module
- `numpy` - Numerical computing library
- `pandas` - Data manipulation and analysis
- `matplotlib` - Data visualization and plotting

### Dataset
The notebook works with two datasets:
- **X**: `[2, 4, 6, 8, 3, 5, 1, 10, 12, 11]`
- **Y**: `[4, 5, 6, 7, 8, 9, 10, 12, 13, 11]`

### Statistical Operations Performed

1. **Descriptive Statistics**
   - Mode calculation for both datasets using `statistics.mode()`

2. **Data Visualization**
   - Histograms for X and Y distributions
   - Box plots for X and Y to visualize data spread and outliers

### Visualizations Created
- **Histograms**: Show frequency distribution of values
  - X values histogram with labeled axes
  - Y values histogram with labeled axes
  
- **Box Plots**: Display data quartiles and potential outliers
  - Box plot for X dataset
  - Box plot for Y dataset
