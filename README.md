# Python for Data Science — a hands-on tutorial

A step-by-step path from core Python to the foundations of data science. Built
from real coursework and reworked into a practical, DataCamp-style tutorial.

Every topic folder has the same three things:

1. **`README.md`** — a short, exam-focused explanation of the concept.
2. **A real program** — a complete, runnable app, not a toy snippet.
3. **`exercises.py` + `solutions.py`** — fill-in-the-blank practice (replace each
   `____`), with a self-check (`PASS`/`FAIL`) and reference answers.

All code is Python 3, reproducible (no user input, seeded randomness), and tested.

## Setup

```bash
python -m venv venv
venv\Scripts\activate         # Windows
# source venv/bin/activate    # macOS / Linux
pip install -r requirements.txt
```

Modules 01–08 need only the standard library; 09–12 use NumPy/pandas/matplotlib/scikit-learn.

## How to use a module

```bash
cd 01_fundamentals
python authenticator.py     # see the real program run
python exercises.py         # fill the blanks, then run to self-check
python solutions.py         # the reference answers
```

Work the modules in order — each assumes the ones before it.

## Applied projects

After the lessons, `projects/` holds small end-to-end programs that *apply* what
the modules teach. Unlike the lesson code these are interactive / use live data.
