# Project — Temperature Forecaster

Asks for a city, looks it up with the Open-Meteo geocoding API, and prints the
current temperature, the next 12 hours, and a 3-day forecast (°C or °F).

**Applies:** Module 05 (error handling — network failures, missing data) and
Module 07 (installing a third-party package, `requests`). Needs internet.

Setup & run:
```bash
pip install requests
python main.py
```
