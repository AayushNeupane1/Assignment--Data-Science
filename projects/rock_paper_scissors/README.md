# Project — Rock, Paper, Scissors

A console game split across several files, the way a small project is really
organised:
- `main.py` — the game loop and score tracking (run this)
- `player.py` — gets and validates the player's move
- `computer.py` — the computer's random move
- `game_logic.py` — decides the winner

**Applies:** Modules 07–08 (modules & project structure), plus functions and a dict.

Run: `python main.py`
