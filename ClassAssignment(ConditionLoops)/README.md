# ClassAssignment(ConditionLoops)

This folder contains basic Python programming assignments focusing on conditional statements and loop structures.

## Files Overview

### 1. [consonantVowel.py](consonantVowel.py)
**Description:** Program to count vowels and consonants in a word
- Takes user input for a word
- Uses a function to count vowels (a, e, i, o, u) and consonants
- Displays total count of vowels and consonants
- **Key Concepts:** String handling, conditional statements, functions

### 2. [dice.py](dice.py)
**Description:** Dice rolling simulator that tracks the number of 6s
- Simulates rolling a dice 10 times using `random.randint()`
- Counts and displays how many times a 6 appears
- Prints each roll result with its roll number
- **Key Concepts:** Loops, random module, counting, conditionals

### 3. [largest.py](largest.py)
**Description:** Program to find the largest of three numbers
- Accepts three numbers as user input
- Uses a function to determine the largest number
- Compares numbers using conditional statements
- **Key Concepts:** Functions, conditionals, variables

### 4. [marksheet.py](marksheet.py)
**Description:** Student grading system with marks calculation
- Accepts number of students and their marks
- Calculates total marks, average, and assigns grades
- Grade assignment: A+ (90+), A (80+), B (70+), C (60+), D (50+), F (<50)
- Displays complete student report with all details
- **Key Concepts:** Lists, loops, functions, conditionals, data organization

### 5. [multiplicationTable.py](multiplicationTable.py)
**Description:** Multiplication table generator with special formatting
- Takes a number as input and generates its multiplication table (1-10)
- Highlights multiples of 5 with bold formatting
- Uses ANSI escape codes for text styling
- **Key Concepts:** Loops, conditionals, formatting, modulo operator
