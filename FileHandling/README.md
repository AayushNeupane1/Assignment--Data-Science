# File Handling

This folder contains Python programs demonstrating various file handling operations.


### 1.py - Read Text File
- Opens and reads a text file (`qst1.txt`)
- Prints all contents
- Handles `FileNotFoundError` exception

### 2.py - Count Words and Lines
- Reads a text file (`qst2.txt`)
- Counts and displays the number of words
- Counts and displays the number of lines
- Includes error handling

### 3.py - User Data Input
- Takes user's name and age as input
- Saves the data to a text file (`qst3.txt`) in append mode
- Implements exception handling

### 4.py - CSV File Reading
- Reads a CSV file (`qst4.csv`)
- Extracts and prints names from the first column
- Handles file not found errors

## Text Files
- `qst1.txt` - Sample text file for reading
- `qst2.txt` - Sample text file for word and line counting
- `qst3.txt` - Output file for user data storage
- `qst4.csv` - Sample CSV file with data
